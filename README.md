# Checklist de diseño de páginas web para pymes

Lista práctica para revisar antes de lanzar el sitio web de tu pyme en Colombia. Revisa cada punto antes de publicar.

## Antes de publicar

**Objetivo.** Define una sola acción por página: cotizar, llamar, escribir por WhatsApp o comprar.

**Velocidad.** Imágenes comprimidas, buen hosting y carga en menos de 3 segundos.

**Móvil.** Diseño responsive probado en un celular real.

**SEO básico.** Un solo H1, títulos ordenados, meta título, meta descripción y URLs cortas.

**Mensaje claro.** En la primera pantalla debe quedar claro qué ofreces, para quién y cuál es el siguiente paso.

**Llamados a la acción.** Botones visibles y formularios cortos.

**Confianza.** Testimonios reales, casos, logos y datos de contacto verificables.

**Seguridad y legales.** Certificado SSL, política de privacidad y aviso de cookies.

**Analítica.** Google Analytics, Search Console y seguimiento de formularios y clics en WhatsApp.

**Mantenimiento.** Respaldos, actualizaciones y dominio y hosting a tu nombre.
